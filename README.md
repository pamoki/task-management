# タスク管理アプリ

## 概要
チームで利用できるタスク管理アプリを開発しました。
直感的に操作できるUIを意識して設計しています。

## 使用技術
- Flutter
- Dart
- PostgresSQL

## 主な機能
- タスクの追加・削除
- タスクの状態管理（未完了 / 完了）
- 情報の閲覧・編集
- 目標共有グループの作成・検索
- グループ内でのチャット・情報閲覧
- グループ作成者による管理メニュー
- グループ作成者によるグループへの招待機能
- グループの削除機能
- 達成報酬によるガチャ要素
- ガチャ報酬でのバトル要素

## 担当箇所
- UI設計
- 外部設計
- 画面実装
- ロジック開発

## 工夫した点
- 視認性を高めるためにシンプルなデザインを心がけた
- 整列や近接などのデザインの基礎を徹底した
- ユーザーが直感的に操作できるUIを意識した

## チーム開発での経験

- 意見の違いが出た際は話し合いで方向性を統一した
